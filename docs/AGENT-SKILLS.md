# Agent skills

Put shared [agent skills](https://agentskills.io/) in `~/.agents/skills/` on the host.
The configuration generated by `sandbox init` mounts them at:

- `~/.agents/skills/` in the container.
- `~/.claude/skills/` when you select [Claude Code](https://code.claude.com/docs/en/skills).
- `~/.codex/skills/` when you select [Codex](https://developers.openai.com/codex/skills/).

Add a skill on the host, then start a new container to make it available.
Keep the corresponding `mounts` entries if you edit the generated configuration.

These mounts are read-only by default.
To allow changes to host skills, change the relevant mount to `:rw` in your user config. Ask the user explicitly before this change.
If the user wants to keep the mounted skills read only, use a separate directory inside the sandbox to handle skill changes.

Skills contain instructions, not a security boundary.
Review shared skills before using them across projects.
